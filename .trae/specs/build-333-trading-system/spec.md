# 333交易系统 - 技术规格文档

## 一、项目概述

### 1.1 系统定位

333交易系统是一套**低认知负担的长期趋势资金管理系统**，基于30分钟K线与MA30移动平均线进行中长期趋势跟踪交易。系统核心目标是：**趋势出现时跟随，趋势结束时离场；不让亏损失控；等待大行情奖励**。

### 1.2 核心理念

- **系统型趋势交易**：追求长期统计优势与风险控制，而非短期暴利
- **不预测风会不会来，只保证风来时自己一定在场**
- **周期终会轮回**：信仰趋势跟踪的统计优势

---

## 二、技术架构

### 2.1 核心指标体系

| 指标名称 | 计算方法 | 用途 |
|---------|---------|------|
| **MA30** | 30分钟K线的30周期简单移动平均 | 趋势判断核心基准线 |
| **收盘价** | 每根30分钟K线的收盘价 | 与MA30比较判断趋势方向 |
| **涨跌幅** | (当前价 - 买入价) / 买入价 × 100% | 止盈触发判断 |

### 2.2 数据规格

- **时间周期**：30分钟K线
- **数据源**：ETF行情数据（支持券商API或第三方数据源）
- **交易标的**：ETF产品
- **数据字段**：时间戳、开盘价、最高价、最低价、收盘价、成交量

## 三、交易规则

### 3.1 入场规则（牵手买入）

**触发条件**：
- ETF收盘价 > MA30

**执行动作**：
- 全仓买入

**逻辑说明**：价格站上MA30均线视为趋势启动信号，系统应保持在场。

### 3.2 出场规则（分手卖出）

**触发条件**：
- ETF收盘价 < MA30

**执行动作**：
- 全部清仓

**逻辑说明**：价格跌破MA30均线视为趋势结束信号，系统应离场观望。

## 四、止盈机制（333阶梯止盈）

### 4.1 三阶段止盈规则

| 阶段 | 盈利阈值 | 执行动作 | 保留仓位 |
|------|---------|---------|---------|
| **第一次** | 盈利达到 +1% | 提取利润 | 保留底仓 |
| **第二次** | 盈利达到 +3% | 再次提取利润 | 保留趋势仓 |
| **第三次** | 价格跌破MA30 | 全部离场 | 无 |

### 4.2 止盈逻辑流程

```
┌─────────────────────────────────────────────────────────┐
│                   止盈决策流程                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  持仓中 ──┬── 盈利 < 1% ──▶ 继续持有，继续监控           │
│          │                                              │
│          ├── 1% ≤ 盈利 < 3% ──▶ 第一阶段止盈：提取利润   │
│          │                           保留底仓，继续跟踪    │
│          │                                              │
│          └── 盈利 ≥ 3% ──┬── 价格 > MA30 ──▶ 继续持有   │
│                          │                               │
│                          └── 价格 < MA30 ──▶ 全部清仓    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.3 止盈实现要求

- **利润提取**：将盈利部分转化为现金，保留持仓成本不变
- **底仓保留**：第一次止盈后，保留的底仓成本锁定为目标持仓量
- **趋势仓保留**：第二次止盈后，继续持有趋势仓直至止损信号

## 五、风险管理体系

### 5.1 核心风险控制原则

1. **硬止损**：价格跌破MA30立即清仓
2. **不摊薄成本**：亏损时不加仓
3. **仓位控制**：全进全出的趋势跟踪模式
4. **单标的长期绑定**：避免频繁切换标的

### 5.2 风险管理规则

| 风险类型 | 控制措施 |
|---------|---------|
| 趋势反转风险 | 价格<MA30立即清仓 |
| 追高风险 | 严格遵守买入信号，不提前入场 |
| 踏空风险 | 保持高系统信仰，不轻易离场 |
| 单标的风险 | 长期绑定单一ETF，等待主升浪 |

### 6.2 模块职责定义

#### 6.2.1 数据采集模块

- **职责**：获取30分钟K线数据
- **输入**：ETF代码、时间范围
- **输出**：K线数据数组
- **技术要求**：
  - 支持实时数据推送或定时轮询
  - 数据缓存机制
  - 断线重连

#### 6.2.2 指标计算模块

- **职责**：计算MA30及其他辅助指标
- **输入**：K线数据
- **输出**：MA30数值、当前价格、涨跌幅
- **计算公式**：
  ```
  MA30 = SUM(收盘价, 30) / 30
  ```

#### 6.2.3 信号生成模块

- **职责**：根据规则判断交易信号
- **信号类型**：
  - 买入信号：价格上穿MA30
  - 卖出信号：价格下穿MA30
  - 止盈信号：盈利达到1%或3%
- **输出**：交易信号对象（类型、时间、价格、原因）

#### 6.2.4 仓位管理模块

- **职责**：管理当前持仓状态和成本
- **状态跟踪**：
  - 空仓 / 持仓中 / 止盈中（一阶段）/ 止盈中（二阶段）
  - 买入价格、买入时间
  - 已提取利润金额
- **输出**：当前仓位状态

#### 6.2.5 订单执行模块

- **职责**：对接券商API执行交易指令
- **功能**：
  - 买入下单（全仓）
  - 卖出下单（清仓/部分止盈）
  - 订单状态查询
  - 成交回报处理

#### 6.2.6 交易日志模块

- **职责**：记录所有交易行为和系统状态
- **记录内容**：
  - 信号触发时间、价格、原因
  - 订单提交时间、价格、数量
  - 成交时间、价格、数量
  - 持仓变化记录
  - 利润计算记录

## 八、交易决策引擎

### 8.1 决策流程伪代码

```
FUNCTION trading_decision(current_data, position):
    
    // 获取当前价格和MA30
    current_price = current_data.close
    ma30 = calculate_ma30(current_data)
    
    // 计算盈亏
    IF position.status == "HOLDING" THEN
        profit_rate = (current_price - position.entry_price) / position.entry_price
    ELSE
        profit_rate = 0
    END IF
    
    // 趋势判断
    IF current_price > ma30 THEN
        trend = "UPTREND"
    ELSE
        trend = "DOWNTREND"
    END IF
    
    // 决策分支
    IF position.status == "EMPTY" THEN
        // 空仓状态
        IF trend == "UPTREND" THEN
            RETURN SIGNAL_BUY
        END IF
    ELSE IF position.status == "HOLDING" THEN
        // 持仓状态
        IF trend == "DOWNTREND" THEN
            RETURN SIGNAL_SELL_FULL  // 分手，全部清仓
        END IF
        
        // 检查止盈
        IF profit_rate >= 0.03 AND position.stop_loss_stage == 1 THEN
            RETURN SIGNAL_TAKE_PROFIT_STAGE2
        ELSE IF profit_rate >= 0.01 AND position.stop_loss_stage == 0 THEN
            RETURN SIGNAL_TAKE_PROFIT_STAGE1
        END IF
    END IF
    
    RETURN SIGNAL_HOLD
END FUNCTION
```

### 8.2 状态转换表

| 当前状态 | 触发条件 | 新状态 | 执行动作 |
|---------|---------|--------|---------|
| EMPTY | 价格>MA30 | HOLDING | 全仓买入 |
| HOLDING | 价格<MA30 | EMPTY | 全部清仓 |
| HOLDING | 盈利≥1% | HOLDING | 第一阶段止盈 |
| HOLDING | 盈利≥3% | HOLDING | 第二阶段止盈 |
| HOLDING | 盈利<0 | HOLDING | 继续持有，不操作 |

## 十二、系统约束

### 12.1 执行约束

- **不预测**：不基于主观判断提前入场或离场
- **机械执行**：信号触发即执行，不犹豫
- **高系统信仰**：不在执行中动摇策略

### 12.2 性能要求

- **信号延迟**：从价格变化到信号生成不超过5秒
- **订单延迟**：从信号到订单提交不超过2秒
- **系统可用性**：7×24小时运行（非交易时段低功耗）
