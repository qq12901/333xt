# 333交易系统 V2.0 - Web可视化控制面板

## Why
当前的333交易系统只有命令行界面和简单的打印输出，无法直观地查看策略运行状态、K线走势和交易信号。需要构建一个Web可视化界面，让用户能够实时监控策略运行、查看K线图表、分析账户状态和历史交易记录。

## What Changes

### 核心界面模块
- **K线图表模块** - 基于现有Kline和KlineData模型，展示30分钟K线+MA30均线
- **账户面板模块** - 基于现有SimulatedAccount模型，展示账户余额和持仓状态
- **信号监控模块** - 基于现有Signal和Strategy333模型，实时展示买入/卖出/止盈信号
- **交易记录模块** - 基于现有TradeRecorder模型，展示历史成交记录
- **系统状态模块** - 基于现有MultiDataSourceManager，展示数据源连接状态

### 技术栈
- Streamlit 1.30+ - Web框架
- Plotly - K线图表绘制
- Pandas - 数据处理
- 复用现有src模块 - 数据源、策略、账户系统

## Impact

### Affected specs
- 原有333策略核心逻辑不变
- 数据源管理系统保持不变
- 账户和持仓系统保持不变

### Affected code
- 新增 `src/web/` 目录
- 新增 `scripts/run_web.py` 启动脚本
- 新增 `examples/web_demo.py` Web界面演示

## ADDED Requirements

### Requirement: K线图表展示
系统**必须**提供30分钟K线图表展示功能，包括：
- K线蜡烛图（阳线/阴线颜色区分）
- MA30均线叠加显示
- 支持缩放和平移
- 显示最新价格和涨跌

#### Scenario: 查看K线图表
- **WHEN** 用户打开Web界面
- **THEN** 显示最近100根30分钟K线蜡烛图
- **AND** 叠加显示MA30均线（紫色线条）
- **AND** 右侧显示最新价格和涨跌幅

---

### Requirement: 账户状态展示
系统**必须**提供账户状态实时展示，包括：
- 可用资金余额
- 当前持仓信息（代码、价格、数量、成本）
- 持仓盈亏（金额和百分比）
- 总资产和今日盈亏

#### Scenario: 查看账户状态
- **WHEN** 用户查看账户面板
- **THEN** 显示可用资金
- **AND** 如果有持仓，显示持仓详情
- **AND** 实时更新持仓盈亏

---

### Requirement: 信号监控面板
系统**必须**提供交易信号实时监控，包括：
- 当前趋势状态（多头/空头）
- 最新信号类型（买入/卖出/止盈）
- MA30数值
- 价格与MA30的关系

#### Scenario: 查看策略信号
- **WHEN** 系统检测到新信号
- **THEN** 信号面板高亮显示
- **AND** 显示信号类型、时间戳、价格、原因
- **AND** 信号自动记录到交易历史

---

### Requirement: 交易记录展示
系统**必须**提供历史交易记录查看，包括：
- 所有买入/卖出记录
- 成交时间、价格、数量
- 手续费信息
- 盈亏统计

#### Scenario: 查看交易记录
- **WHEN** 用户点击交易记录标签
- **THEN** 显示所有历史交易记录表格
- **AND** 支持按日期筛选
- **AND** 显示总交易笔数和胜率

---

### Requirement: 系统状态监控
系统**必须**提供系统运行状态监控，包括：
- 当前数据源名称和状态
- K线数据条数
- 最后更新时间
- 系统运行时间

#### Scenario: 查看系统状态
- **WHEN** 用户查看系统状态
- **THEN** 显示当前使用的数据源
- **AND** 显示已加载K线数量
- **AND** 显示数据最后更新时间

---

### Requirement: 参数配置界面
系统**应该**提供策略参数配置，包括：
- MA周期配置（默认30）
- 止盈目标配置（1%、3%）
- 初始资金配置

#### Scenario: 配置策略参数
- **WHEN** 用户在配置面板修改参数
- **THEN** 参数实时生效
- **AND** 参数变化自动保存

---

### Requirement: 回测入口
系统**应该**提供历史回测入口，包括：
- 起始日期和结束日期选择
- 回测运行按钮
- 回测结果展示（收益率、最大回撤等）

#### Scenario: 运行历史回测
- **WHEN** 用户选择回测时间范围并点击运行
- **THEN** 系统使用历史数据运行回测
- **AND** 显示回测绩效指标

---

### Requirement: 实时数据自动刷新
系统**应该**支持实时数据自动刷新，包括：
- 可配置刷新间隔（默认30秒）
- 手动刷新按钮
- 自动停止机制（交易时间外）

#### Scenario: 自动刷新数据
- **WHEN** 用户启用自动刷新
- **THEN** 每隔指定秒数自动更新数据
- **AND** 图表和账户状态同步更新

---

## Technical Implementation

### 目录结构
```
src/web/
├── __init__.py
├── app.py              # Streamlit主应用
├── components/         # UI组件
│   ├── __init__.py
│   ├── kline_chart.py # K线图表组件
│   ├── account_panel.py # 账户面板组件
│   ├── signal_monitor.py # 信号监控组件
│   └── trade_history.py # 交易记录组件
└── utils.py           # 工具函数
```

### 依赖关系
- 复用 `src.datasources.*` - 数据源
- 复用 `src.strategy.*` - 策略逻辑
- 复用 `src.execution.*` - 账户管理
- 复用 `src.models.*` - 数据模型
- 新增 `streamlit`, `plotly`, `pandas` 依赖
