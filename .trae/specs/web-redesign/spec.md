# 333交易系统 V2.0 - 极简实用Web界面重构

## Why
当前的Web界面功能过于复杂，不符合333交易系统"简洁、实用、低认知负担"的核心设计理念。需要重新设计一个极简界面，让用户一眼看清当前状态和下一步操作建议。

## What Changes

### 设计原则
1. **极简主义** - 只展示最核心的信息，不花哨
2. **一眼可见** - 当前状态一目了然
3. **操作建议** - 明确给出下一步操作建议
4. **实时更新** - 数据自动刷新，实时反映市场状态

### 界面重构
- **单页面设计** - 不使用多标签页，所有信息一屏展示
- **核心指标突出** - 价格、MA30、持仓状态、盈亏最大化展示
- **信号建议明确** - 下一个预期操作（买入/卖出/观望）
- **简化图表** - K线用简洁的价格线代替复杂蜡烛图
- **去掉冗余** - 删除复杂的参数配置、筛选功能

## Impact

### Affected code
- 重构 `src/web/app.py` - 极简单页面设计
- 删除多余组件目录 - 简化项目结构

## ADDED Requirements

### Requirement: 极简单页面布局
系统**必须**提供单页面布局，在一页内展示所有核心信息：
- 顶部：交易标的 + 当前价格 + 涨跌
- 中部左侧：账户状态（余额、持仓、盈亏）
- 中部右侧：333策略分析（MA30、趋势、信号）
- 底部：下一个操作建议
- 右下角：简洁的刷新按钮

#### Scenario: 查看交易状态
- **WHEN** 用户打开Web界面
- **THEN** 所有核心信息在一屏内完整展示
- **AND** 不需要切换标签页
- **AND** 信息优先级清晰（操作建议最重要）

---

### Requirement: 核心状态展示
系统**必须**清晰展示以下核心状态（按重要性排序）：
1. **下一个操作** - 最重要，红色大字显示
2. **当前持仓** - 空仓/持仓+盈亏
3. **MA30关系** - 价格与MA30的关系
4. **账户余额** - 可用资金

#### Scenario: 一眼看清状态
- **WHEN** 用户快速扫视界面
- **THEN** 能立即知道下一步应该做什么
- **AND** 能立即知道当前盈亏状态

---

### Requirement: 333策略信号展示
系统**必须**明确展示333策略的当前信号：
- 当前趋势（多头/空头）
- 价格与MA30关系（上方/下方）
- 下一个预期信号（买入/卖出/观望）
- 止盈目标（如果持仓）

#### Scenario: 查看策略信号
- **WHEN** 用户查看策略信号
- **THEN** 明确显示当前趋势和下一个预期操作
- **AND** 用颜色区分（绿色=买入机会，红色=卖出机会）

---

### Requirement: 简洁价格线
系统**应该**用简洁的价格折线图代替复杂蜡烛图：
- 只显示收盘价折线
- 叠加MA30均线
- 近30根K线数据
- 悬停显示具体数值

#### Scenario: 查看价格走势
- **WHEN** 用户想看价格走势
- **THEN** 显示简洁的折线图
- **AND** 不需要复杂的蜡烛图

---

### Requirement: 自动实时刷新
系统**必须**支持自动实时刷新（默认30秒）：
- 无需用户操作，自动更新
- 显示最后更新时间
- 手动刷新按钮（备用）

#### Scenario: 自动更新
- **WHEN** 界面打开时
- **THEN** 每30秒自动刷新数据
- **AND** 界面实时反映最新状态

---

## Technical Implementation

### 简化目录结构
```
src/web/
├── app.py              # 极简单页面应用（只有这一个文件）
└── __init__.py
```

### 依赖
- Streamlit - Web框架（已安装）
- 复用现有src模块（数据源、策略、账户）
- 无需Plotly图表库（用st.line_chart代替）

### 代码风格
- 保持简洁，不超过200行代码
- 使用Streamlit原生组件
- 无复杂CSS样式
- 注释清晰易懂
