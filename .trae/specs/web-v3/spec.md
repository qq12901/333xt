# 333交易系统 V3.0 - 创意UI升级方案

## Why
当前UI太简单，没有体现333交易系统的特色：
- "牵手买入/分手卖出" 不够形象
- 止盈目标进度不直观
- 缺少K线蜡烛图+MA30均线可视化
- 缺少历史信号记录

## What Changes
- 🎯 超大"下一个操作"展示
- 📈 K线蜡烛图+MA30均线专业图表
- 🏁 止盈进度条+里程碑
- 📋 333策略卡片化设计
- 📜 历史信号记录
- ✨ "牵手/分手"视觉效果

## Impact
- Affected: src/web/app.py
- Dependencies: streamlit, plotly

## ADDED Requirements

### Requirement: K线蜡烛图+MA30均线
- 蜡烛图显示30分钟K线
- MA30均线叠加显示
- 鼠标悬停显示详情

### Requirement: 止盈进度条
- 彩色进度条显示距离1%/3%目标
- 里程碑标记
- 直观进度展示

### Requirement: 策略卡片
- 4个卡片：牵手买入、分手卖出、一阶止盈、二阶止盈
- 点击卡片看详情
- 形象化展示策略规则

### Requirement: 历史信号记录
- 显示最近信号列表
- 显示价格、时间、信号类型
- 可点击查看详情
